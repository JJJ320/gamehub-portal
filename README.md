# GameHub Portal

Crie a primeira versão do meu portal de jogos chamado GameHub. É uma migração conceitual do projeto que comecei no Replit, então quero priorizar progresso rápido e uma base bonita, funcional e fácil de expandir. O portal reunirá jogos já existentes, mas nesta primeira versão use apenas dados e artes demonstrativos de catálogo; não copie, hospede ou distribua arquivos protegidos de jogos reais. O visual deve ser um portal gamer premium dark-first: fundo quase preto/azul-marinho, acentos roxo/violeta, tipografia forte, bordas discretas, cards escuros, imagens grandes e bastante contraste. A home deve ter header com logo GAMEHUB, navegação Início, Todos os Jogos, Categorias, Mais Jogados e Novos Jogos, campo de busca e botão Entrar. Crie um hero grande de destaque para Granny com imagem de terror, título, descrição curta e botão JOGAR AGORA. Ao lado, ranking Mais Jogados com Subway Surfers, Granny, 1v1.LOL, Stumble Guys e Friday Night Funkin'. Abaixo, seção Jogos em Destaque com Granny, Subway Surfers, 1v1.LOL, Stumble Guys, Free Fire e Minecraft Classic; depois Novos Jogos com The Baby in Yellow, Death Park 2, Ice Scream 8, Evil Nun Maze, Among Us e Roblox. Inclua uma coluna lateral de Categorias: Ação, Aventura, Terror, Corrida, Multiplayer, Puzzle e Esportes. Cards devem mostrar capa, nome, nota e gênero. Faça busca funcional, filtros por categoria, navegação entre seções/páginas, cards clicáveis e uma página/estado de detalhes do jogo com informações e botão de jogar desabilitado ou demonstrativo quando não houver versão web autorizada. Crie dados mock centralizados para que futuramente seja fácil adicionar jogos autorizados. Faça o layout totalmente responsivo para desktop, tablet e celular, com boas animações de hover e transições discretas. Não invente backend, pagamentos ou autenticação real nesta primeira etapa; apenas deixe a arquitetura preparada para futuras contas, favoritos, avaliações, ranking, banco de dados e execução de versões web autorizadas. Entregue uma primeira versão polida e funcional, não apenas um wireframe.
